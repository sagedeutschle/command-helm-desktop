# Authorship and scope

This welcome extension is original Command Helm code and interface work, proposed under the MIT license in this directory. It uses Node built-ins and the public VS Code extension API, with no bundled dependencies, copied upstream editor implementation, external assets or fonts.

Command Helm uses an upstream VS Code/VSCodium editor foundation. The extension's MIT license applies only to these original extension files. Upstream components retain their respective notices and licenses; the editor and other extensions require their own distribution inventory and review.
